# Spiceworks Ticketing System

A hands-on help desk ticketing project demonstrating core IT support workflows in Spiceworks. The project includes creating, documenting, updating, resolving, and closing support tickets while maintaining clear communication with end users.

<h2>Description</h2>

This project demonstrates practical experience using the Spiceworks ticketing system to manage common help desk support requests from initial intake through resolution. It highlights essential entry-level IT support skills, including ticket creation, issue documentation, end-user communication, and ticket closure.

<br />

<h2>Skills Demonstrated</h2>

- Help desk ticket creation, categorization, and tracking
- End-user support communication and follow-up
- Documentation of reported issues, troubleshooting actions, and resolutions
- Resolution verification and proper ticket closure
- Professional written communication and customer-service practices

<h2>Tools and Technologies Used</h2>

- <b>Spiceworks Help Desk</b>
- <b>Web-based ticket management system</b>

<h2>Environment Used</h2>

- <b>Spiceworks ticketing environment</b>
- <b>Simulated help desk / end-user support workflow</b>
